SHIPÁ - локальный запуск (не GitHub Pages)

Windows:
  1. Распакуйте ZIP целиком в обычную папку (не запускайте файлы внутри ZIP).
  2. Дважды нажмите START_WINDOWS.bat.
  3. Откройте http://localhost:8000, если браузер не открылся сам.

macOS:
  Распакуйте ZIP, откройте START_MAC.command (при необходимости через контекстное меню «Открыть»).
  Альтернатива в терминале: cd <папка с проектом> && python3 -m http.server 8000

Linux:
  ./START_LINUX.sh

Требование: Python 3. Внешние npm-пакеты не нужны.
Остановить сервер: Ctrl+C в терминале.

Раздел «Кухня» теперь открывается внутри этого же локального сайта, без перехода на GitHub Pages.
Остальные внешние ссылки (например, карты, WhatsApp, Google Fonts) по-прежнему требуют интернета.

Важно: это локальный просмотр исходного HTML-прототипа. Реальная оплата/отправка заявок требуют
подключения сервисов и не становятся работающими от запуска локального сервера.

Для первого открытия нужен интернет: React/ReactDOM загружаются исходным DC-runtime с CDN.
По адресу github.com или GitHub Pages проект запускать/публиковать не требуется.

Поля текущей формы: имя и телефон. Поле электронной почты в исходном проекте отсутствует:
новое поле без требования не добавлялось. Проверка формата email предусмотрена
в коде, если такое поле появится в дальнейшем.
