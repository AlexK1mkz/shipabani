# SHIPÁ — анимации и мобильная адаптация (28.10.2026)

Основа: `SHIPA_final_kaspi_gallery_booking_time.zip`, без изменения тарифов, оплаты Kaspi, форм, текстов и бизнес-логики.

## Изменено

- Основные экраны (главная, дома, дом, услуги, кухня, отзывы, о нас, контакты): мягкая смена страницы с коротким уходом старого экрана и появлением нового, при поддержке браузером View Transitions. В браузерах без View Transitions — самостоятельная анимация появления нового экрана.
- Плавное появление блоков во время прокрутки на страницах, где ранее этого не было.
- Небольшой каскад появления карточек в каталоге, услугах, кухне и отзывах.
- Ненавязчивый hover на карточках каталога для устройств с мышью. На сенсорных экранах эффект hover не залипает.
- При системной настройке «Уменьшение движения» дополнительные анимации выключены.
- Мобильный каталог 320–599 px: гибкая одна колонка без вылезания за экран, две адаптивные кнопки на карточке.
- На экранах до 374 px характеристики каталога занимают две колонки вместо четырёх. Характеристики на странице отдельного дома также показываются в две колонки на узких экранах.
- Лента миниатюр фотогалереи на мобильных начинается слева, поэтому первое фото доступно при горизонтальной прокрутке.
- Карточки услуг и кухни лучше переносят длинные названия и цену; номер телефона на странице контактов может переноситься.
- Исправлена повторная инициализация `isWide`, из-за которой десктоп мог сначала появляться в мобильном режиме.

## Проверки

- `node --test analytics-tests/*.test.cjs i18n-tests/*.test.cjs validation-tests/*.test.cjs motion-tests/*.test.cjs`
- Синтаксис JS: `node --check` для основного скрипта и связанных файлов.
- Изолированная проверка CSS каталога в Chromium на 320, 360, 375, 390, 430, 600, 768, 1024 px: горизонтального переполнения нет. При `prefers-reduced-motion: reduce` анимация отключена.
- **Ограничение:** полный сайт в браузере Chromium внутри этой среды не удалось открыть из-за `ERR_BLOCKED_BY_ADMINISTRATOR`. Поэтому это не заявляется как полное сквозное тестирование всех экранов, в частности бронирования на физических iPhone и Android. Рекомендуется финальная визуальная проверка в Chrome/Safari.

## Локальный запуск

Windows: `START_WINDOWS.bat`, macOS: `START_MAC.command`, Linux: `START_LINUX.sh`. Адрес: `http://localhost:8000`. Нужен Python 3; зависимости интерфейса загружаются из CDN, поэтому для первого открытия нужен интернет. GitHub не требуется.
