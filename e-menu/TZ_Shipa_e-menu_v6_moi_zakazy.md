# ТЗ v6 для Claude Design: «Мои заказы» — детализация заказа

Основа — ТЗ v3, v4, v5 (`uploads/`), они остаются в силе. Эта правка дополняет раздел «Мои заказы». Кнопка **«Повторить» остаётся**.

---

## 1. Что сохраняем при отправке заказа

В момент нажатия «Отправить заказ» сохраняем **снимок заказа** целиком (`localStorage`, ключ `shipa-emenu-orders`, последние 10 заказов за 24 часа, все обращения в `try/catch`):

```js
{
  id: 'o_1727381580000',          // внутренний, гостю не показываем
  sentAt: 1727381580000,          // время отправки
  house: { id:'sila', n:'02', name:'СИЛА' },
  serve: { mode:'ready' } | { mode:'time', at:'01:15', date:'28.09' },
  guest: 'Димон',                 // может быть пустым
  comment: 'без лука',            // может быть пустым
  lang: 'RU',
  lines: [                        // цены и названия на момент заказа
    { id:'besh', name:['Бешбармак','Бесбармақ','Beshbarmak'], group:'order',
      qty:1, price:32000, img:'assets/menu/besh.jpg' },
    …
  ],
  subtotal: 62500, service: 6250, total: 68750
}
```

Названия и цены сохраняем в снимке, чтобы детализация показывала ровно то, что ушло в WhatsApp, даже если меню потом поменяется.

## 2. Список «Мои заказы» (шторка)

Карточка заказа (белая, рамка `--line`, радиус `--r-md`, отступы 16):

```
┌──────────────────────────────────────────────┐
│ Сегодня, 01:13                     68 750 ₸  │
│ Дом 02 · СИЛА · 5 позиций                    │
│ [фото][фото][фото][+2]                       │
│ ──────────────────────────────────────────── │
│ Подробнее ›                      [Повторить] │
└──────────────────────────────────────────────┘
```
- **Первая строка:** «Сегодня, 01:13» / «Вчера, 23:40» (Inter 16/600), справа итог (tabular-nums).
- **Вторая строка:** дом и количество позиций, 14 px `--ink-2`.
- **Миниатюры:** 3 фото по 40×40 (радиус 10) и плитка «+N», если позиций больше. Используются настоящие фото позиций, не знак-заглушка.
- **Нижний ряд:** слева текстовая кнопка «Подробнее ›» (navy 15/600), справа «Повторить» (pill `--surface`, 40 px).
- **Нажатие на всю карточку** (кроме «Повторить») открывает детализацию.
- **Порядок:** новые сверху.
- **Пустое состояние:** знак SHIPÁ 40 px на 30 % прозрачности и текст «Здесь появятся отправленные заказы».

## 3. Детализация заказа (экран поверх шторки)

Открывается свайпом влево внутри той же шторки (push-переход 250 мс), сверху кнопка «‹ Мои заказы». Фон белый.

1. **Шапка:**
   - Cormorant 28 «ЗАКАЗ»;
   - под ним «Сегодня, 01:13 · Дом 02 · СИЛА» (14 px `--ink-2`);
   - справа бейдж-pill «Отправлен в WhatsApp» (`--surface`, иконка Lucide `check` 14, текст 12/600).
2. **Детали** (список «ключ — значение», 15 px, строки через `--line`):
   - Подать: «По готовности» или «К 01:15»;
   - Гость: «Димон» (если есть);
   - Комментарий: «без лука» (если есть, многострочный).
3. **Позиции** по тем же группам, что в корзине и сообщении: «Кухня и напитки», «Парение — заявка», «Аренда — вернуть при выезде», «Покупки».

   Строка позиции: фото 48 (радиус 10), название 15/600 на языке интерфейса, под ним «2 × 3 500 ₸» 13 `--ink-2`, справа сумма строки 15/600.

   Счётчиков нет, экран только для просмотра.
4. **Итог:**
   ```
   Сумма                     62 500 ₸
   Обслуживание 10%           6 250 ₸
   ИТОГО                     68 750 ₸   ← Cormorant 28
   ```
5. **Липкий низ** (белый, линия `--line` сверху, с учётом safe-area):
   - главная кнопка brick на всю ширину: **«Повторить заказ»**;
   - под ней текстовая кнопка «Написать администратору об этом заказе». Она открывает WhatsApp с текстом `*SHIPÁ*\n*Дом 02 · СИЛА*\nВопрос по заказу от 01:13:\n` (без эмодзи, правила из v4).

## 4. Логика «Повторить»

Одинаковая для кнопки в списке и в детализации.

1. Берём позиции из снимка **по текущему меню** (`ITEMS` по `id`).
2. **Если корзина пустая,** кладём позиции сразу, открываем экран заказа, тост «Заказ добавлен в корзину».
3. **Если в корзине уже что-то есть,** показываем маленькую шторку:
   - «В корзине уже есть позиции» и две кнопки: **«Добавить к текущим»** (brick) и **«Заменить корзину»** (контурная);
   - «Отмена» текстом.
4. **Цены** берём текущие. Если сумма отличается от сохранённой, в экране заказа под итогом на 4 с появляется строка «Цены обновлены по текущему меню».
5. **Недоступные позиции** (нет в меню или отмечены «Нет сегодня») пропускаем, тост: «2 позиции сейчас недоступны: Судак на углях, Пуэр шу 2018».
6. **Время подачи** не копируем, ставим «По готовности». **Имя** подставляем из снимка, **комментарий** не копируем.
7. **Дом:** если текущий дом другой, берём **текущий** выбранный дом (гость мог переехать или телефоном пользуется другая компания).

## 6. Приёмка

1. Отправить 2 разных заказа. В «Моих заказах» 2 карточки с настоящими миниатюрами, новые сверху.
2. Детализация показывает время, дом, «Подать», гостя, комментарий, позиции по группам и итог с обслуживанием 10 %. Всё совпадает с текстом, ушедшим в WhatsApp.
3. «Повторить»:
   - с пустой корзиной позиции кладутся сразу;
   - с непустой появляется выбор «Добавить / Заменить»;
   - недоступная позиция пропущена с тостом.
4. Скриншоты на 390 px: список, детализация и шторка выбора «Добавить / Заменить».
