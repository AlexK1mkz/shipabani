# ТЗ v5 для Claude Design: правки e-menu SHIPÁ

Основа — ТЗ v3 и v4 (`uploads/`), они остаются в силе. Здесь две правки, у них приоритет над всем остальным.

---

## 1. Название бренда: SHIPÁ

Правильное написание — **SHIPÁ** (ударная Á в конце, как в логотипе). Написание «SHIPÁA» в прошлых ТЗ ошибочное.

**Заменить везде:**
- интерфейс;
- `I18N` на трёх языках;
- названия товаров: «Полотенце SHIPÁ», «Кружка SHIPÁ»;
- раздел «SHIPÁ с собой» / «SHIPÁ-ны бірге ал» / «Take SHIPÁ home»;
- заголовок «Популярное в SHIPÁ»;
- `alt` у логотипов, `<title>`, сообщение WhatsApp.

Проверка: поиск по проекту `SHIPÁA` и `SHIPAA` в видимых текстах даёт 0 совпадений. Имя файла `SHIPAA e-menu.dc.html` можно не трогать.

Вместо «Заказ из меню SHIPÁA» пишем просто **SHIPÁ**:

Подать: по готовности
Гость: Димон

*Кухня и напитки*
• Бешбармак × 1 — 32 000 ₸

• Тёплый салат с говядиной × 1 — 6 500 ₸

Сумма: 62 500 ₸

Остальные правила сообщения остаются из v4: без эмодзи, `api.whatsapp.com/send`, `encodeURIComponent`, переносы `\n`.

## 3. Фотографии: у каждой позиции

**Что сейчас.** Вместо фото стоят слоты `image-slot` с подписью «Фото: … or browse files». Это места для загрузки, а не фото.

**Как должно быть.** У всех 50 позиций, 4 плиток, баннеров и 8 домов показывается фото, и ни одного слота с текстом на экране нет.

### 3.1 Подключение фото
1. Все фото меню лежат в `assets/menu/` и называются по `id` позиции: `assets/menu/besh.jpg`, `assets/menu/pickles.jpg` и так далее. Полный список имён — в файле `uploads/SHIPA_photo_prompts.md`.
2. В `ITEMS` у каждой позиции `img: 'assets/menu/' + id + '.jpg'`. Для строки списка и мини-карточек тот же файл, `object-fit: cover`.
3. **Фото, которые уже есть**, сразу скопировать в `assets/menu/` под нужными именами:

   | id | Файл-источник |
   |---|---|
   | classic | `h2_acc.png` |
   | herbal | `h8_acc.png` |
   | conifer | `h5_acc.png` |
   | soft | `h1_acc.png` |
   | massage | `h6_acc.png` |
   | tub | `h1_int.png` |
   | t_towel | `h3_acc.png` |
   | t_hat | `h7_acc.png` |
   | t_turban | `h4_acc.png` |

   Дома — `h1…h8_int.png`.
4. **Генерация.** Если в Claude Design доступна генерация изображений, сгенерировать недостающие фото по промтам из `uploads/SHIPA_photo_prompts.md`: общий стиль плюс описание позиции, формат 1:1, 1024×1024. Сохранить под именами из списка.
5. **Если сгенерировать нельзя,** `image-slot` на экране **не показывать**. Вместо него `<img src="assets/menu/{id}.jpg">`, а при ошибке загрузки (`onerror`) аккуратная заглушка: фон `#F5F5F4` и знак `mark-navy.png` 28 px по центру на 25 % прозрачности, **без текста и без «browse files»**. Как только файл с нужным именем появится в `assets/menu/`, фото подхватится само, без правки кода.
6. **Фото Coffee BOOM** (`assets/cb/*`) и ссылки на их CDN удалить.

| Плитка «Напитки» | `assets/menu/samovar.jpg` |

### 3.3 Приёмка
- На экране нет ни одного текста «Фото: …» и «browse files».
- В списке, плитках, шторке, корзине и «Добавить к заказу?» у каждой позиции картинка.
- В проекте нет файлов и ссылок Coffee BOOM.
- `SHIPÁA` нигде не встречается.
- Первая строка сообщения — `*SHIPÁ*`.
